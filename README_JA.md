## こんにちは、lzr52o です 👋

iOS のプロキシツールや自動化スクリプトをいじっています。

### 私について

- Surge / Quantumult X / Loon 用のモジュールとルールのコレクションを管理しています
- 繰り返しの作業はスクリプトやボットに自動で任せるのが好きです
- デバイス：iPhone 16 Pro Max · Mac mini M4

### リポジトリの使い方

ここにあるものは、コードを掘り返さなくてもそのまま使えます:

- **Surge**: Surge モジュール 306 個のコレクション。リポジトリを開いて使いたいモジュールを見つけ、リンクをコピーして Surge にサブスクリプションとして追加するだけです。
- **QuantumultX**: Quantumult X 用の設定とスクリプト。リポジトリを開いてサブスクリプションリンクをコピーし、Quantumult X に追加します。
- **ConfigIconLibrary**: プロファイルアイコン 19 セット。アイコンのサブスクリプションリンクをコピーして、プロキシアプリのアイコン設定に貼り付けます。
- **Scripting-Scripts**: Scripting App 用スクリプト集、合計 37 個。リポジトリを開いて使いたいスクリプトを見つけ、スクリプト内の説明に従って Scripting App にインストールします。
- **forward-widgets**: 転送ウィジェット集。リポジトリを開いて中の説明に従ってインストールして使います。
- **Glados-Railgun-checkin**: GLaDOS の自動チェックイン。リポジトリの説明に従ってアカウントを設定すれば、毎日自動でチェックインします。

**使い方(共通の手順)**

1. 上のリストから必要なリポジトリを開きます。
2. そのリポジトリの README の説明に従って、サブスクリプションリンクをコピーするか、手順通りに設定します。
3. 対応するアプリに戻って貼り付け・保存し、反映されるのを待ちます。

**よくある質問**

- サブスクリプションが追加できない場合は?まずリンクを最後までコピーできているか確認し、次にネットワークから GitHub にアクセスできるか確認してください。
- どのリポジトリを使えばいいか分からない場合は?Surge だけ使うなら Surge、Quantumult X だけ使うなら QuantumultX、アイコンなら ConfigIconLibrary、スクリプトなら Scripting-Scripts です。
- 質問がある場合は?下の「連絡先」から、Telegram チャンネルまたはボットで連絡してください。
