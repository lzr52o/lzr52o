### How to Use My Repositories

Everything here is ready to use — no need to dig through code:

- **Surge**: A collection of 306 Surge modules. Open the repository, find the module you want, copy its link, and add it as a subscription in Surge.
- **QuantumultX**: Configurations and scripts for Quantumult X. Open the repository, copy the subscription link, and add it in Quantumult X.
- **ConfigIconLibrary**: 19 sets of profile icons. Copy the icon subscription link and paste it into your proxy app's icon settings.
- **Scripting-Scripts**: A collection of scripts for the Scripting App — 37 scripts in total. Open the repository, find the script you want, and install it into the Scripting App following the instructions in the script.
- **forward-widgets**: A collection of forwarding widgets. Open the repository and install them following the instructions there.
- **Glados-Railgun-checkin**: Automatic check-in for GLaDOS. Set up your account following the instructions in the repository, and it will check in for you every day.

**How to use (general steps)**

1. Open the repository you need from the list above.
2. Follow the instructions in that repository's README — copy the subscription link or configure it step by step.
3. Go back to the corresponding app, paste or save it, and wait for it to take effect.

**FAQ**

- Subscription won't add? First check that you copied the full link, then check whether your network can reach GitHub.
- Not sure which repository to use? If you only use Surge, go to Surge; if you only use Quantumult X, go to QuantumultX; for icons go to ConfigIconLibrary, and for scripts go to Scripting-Scripts.
